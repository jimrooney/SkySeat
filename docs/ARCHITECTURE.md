# Architecture

## Overview

SkySeat is a static web project made of HTML pages, CSS, and JavaScript files.

## High-Level Structure

- HTML files define feature screens and UI fragments.
- JavaScript files provide state, behavior, and utility logic.
- CSS/HTML styling fragments define visual presentation.
- `skyseat-next/` holds newer in-progress implementation work.

## Notes

Update this file when module boundaries or page responsibilities materially change.
